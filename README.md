JARVIS // AI-Powered Full Interface
A futuristic, interactive web-based Iron Man JARVIS interface built using HTML5, JavaScript (ES Modules), and MediaPipe Machine Learning models. It tracks hand gestures, face mesh, and body poses in real-time right inside your browser using your webcam!   

✨ Features
Hand Tracking & Gesture Recognition: Detects open palms (repulsor charge), forward thrusts (fire blast), and fists (power down).   

Face Mesh (HUD): Generates a high-tech biometric contour scan over your face.   

Pose Estimation: Renders a full body skeletal tracking grid.   

Particle Effects: Interactive visual FX and particle systems for gesture interactions.   

Zero Backend Required: Runs entirely on the client side via browser WebGL/GPU acceleration and CDN-hosted neural models.   

🚀 Demo & Usage
Open the live deployment URL (hosted via Vercel, Netlify, or GitHub Pages).

Allow webcam permissions when prompted by your browser.

Position yourself in front of the camera and use your hands/gestures to interact with the HUD.
