# 🤖 JARVIS // AI-Powered Full Interface

> *“Sometimes you gotta run before you can walk.”*

A futuristic, interactive web-based Iron Man **JARVIS** interface built using **HTML5**, **JavaScript (ES Modules)**, and **MediaPipe Machine Learning models**. It tracks hand gestures, face mesh, and body poses in real-time right inside your browser using your webcam!

🔗 **Live Demo:** [jarvis-full-html.vercel.app](https://jarvis-full-html.vercel.app/)

---

## ✨ Core Features

* **🖐️ Hand Tracking & Gesture Recognition:**
  * **Open Palm:** Charges the repulsor beams.
  * **Thrust Palm Forward:** Fires an intense particle blast!
  * **Fist:** Powers down the system.
* **🛡️ Biometric Face Mesh (HUD):** Generates a high-tech tactical contour scan over your face.
* **🦴 Pose Estimation:** Renders a full-body skeletal tracking grid.
* **💥 Dynamic Particle Effects:** Real-time visual FX and particle systems built natively with HTML5 Canvas.
* **⚡ Zero Backend Required:** Runs entirely client-side powered by browser WebGL/GPU acceleration and Google's CDN-hosted neural models.

---

## 🚀 Quick Start & Usage

1. Open the live deployment link: [jarvis-full-html.vercel.app](https://jarvis-full-html.vercel.app/)
2. Allow webcam permissions when prompted by your browser.
3. Step back, position yourself in front of the camera, and use hand gestures to control the HUD!

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6 Modules)
* **AI / Computer Vision:** Google MediaPipe Tasks Vision (`@mediapipe/tasks-vision`)
* **Hosting / Deployment:** Vercel
